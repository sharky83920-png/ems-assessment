# 初步評估同步教學系統

EMT-1 初步評估教學工具。教官在自己的「戳戳樂控制台」點步驟，全班學員的手機 + 教室大螢幕同步切換到該動作的口述內容與素材，並可一鍵觸發語音朗讀。

## ⚡ 部署到 GitHub Pages（5 分鐘）

> 這份程式需要放在公開網址上才能讓學員手機掃 QR 進來。最簡單免費的方法是 GitHub Pages。

### 第 1 步 — 註冊 GitHub（如果還沒有）

開 [github.com/signup](https://github.com/signup)，用 Email 註冊，驗證信箱。

### 第 2 步 — 建立 Repository

1. 登入後右上角 `+` → **`New repository`**
2. **Repository name**：填 `ems-assessment`
3. 選 **`Public`**（公開，免費版必須公開）
4. **不勾** README、.gitignore、license 三個選項
5. 點綠色 **`Create repository`**

### 第 3 步 — 上傳檔案

進到剛建好的 repo（畫面有「Quick setup」字樣），點頁面中央那行 **`uploading an existing file`** 連結。

到了上傳頁面：

1. 開檔案總管，進到 `G:\我的雲端硬碟\secondbrain\創作庫\初步評估同步教學\`
2. **按 Ctrl+A 全選**這個資料夾裡的所有檔案和子資料夾
3. **拖進** GitHub 網頁中央的拖放區
4. 等左下角顯示「正在上傳…」結束
5. 滑到頁面底部，點綠色 **`Commit changes`** 按鈕

⚠️ 重要：要拖**檔案們**而不是拖整個「初步評估同步教學」資料夾本身——拖外資料夾 GitHub 會把所有路徑加上前綴。

### 第 4 步 — 啟用 GitHub Pages

1. 回到 repo 主頁（點上方 repo 名稱）
2. 上排找最右邊的 **`Settings`** 分頁
3. 左側選單找 **`Pages`**
4. **`Source`** 區塊：
   - `Branch` 下拉選 **`main`**
   - 右邊資料夾保持 **`/ (root)`**
   - 點 **`Save`**

### 第 5 步 — 等 1–2 分鐘拿網址

回到 `Pages` 頁面，幾分鐘後會出現綠色勾勾和網址，類似：

```
https://你的GitHub帳號.github.io/ems-assessment/
```

**這就是你的公開教學系統網址**——任何電腦、任何手機、任何網路都能開。

## 怎麼用

### 教官（你自己）

| 情境 | 開哪個網址 |
|---|---|
| 課前準備、編輯內容 | `你的網址/#/`，點「教官 · 後台管理」 |
| 上課時 | `你的網址/#/`，點「教官 · 開始上課」 |

### 大螢幕／投影電視

在教室電視/投影機上接的那台電腦，打開：
```
你的網址/#/b/教室代碼
```
這台會出聲（適合連教室喇叭）。

### 學員手機

教官按「學員加入資訊」會顯示 QR Code，學員掃描即可。或自己輸入網址：
```
你的網址/#/s/教室代碼
```
預設靜音（防止全班手機鬧成一團）。

## 想改內容怎麼辦

✅ **直接在「後台管理」改就好**，不用重新部署。
- 改了標題、口述、新增步驟 → Firebase 自動同步
- **下次開網址（任何裝置）都會看到最新版**

❌ 例外：上傳的**圖片/影片**還是只存在當下瀏覽器。要在別台電腦看到一樣的素材，需要按右上「匯出」→ 把 JSON 帶到另一台電腦「匯入」。

## 系統架構

```
┌───────────────┐      ┌──────────────────┐      ┌───────────────┐
│  教官筆電      │      │  Firebase 雲端   │      │  學員手機     │
│ (戳戳樂控制)   │ ←→  │ Realtime DB      │ ←→  │ (顯示+靜音)   │
└───────────────┘      │                  │      └───────────────┘
                       │ - 步驟廣播       │      ┌───────────────┐
                       │ - 內容編輯       │ ←→  │  教室大螢幕   │
                       │ - 鎖狀態         │      │ (顯示+出聲)   │
                       └──────────────────┘      └───────────────┘
```

- **GitHub Pages**：放靜態檔案（HTML/CSS/JS）。免費、永久公開。
- **Firebase Realtime Database**：訊息中繼。免費額度足夠 30 人教室用一年。

## 角色比較

| 角色 | URL 前綴 | 看到什麼 | 音訊預設 | 受教官鎖控制 |
|---|---|---|---|---|
| 🎤 教官 · 上課 | `#/t/XXXX` | 戳戳樂控制台 | — | — |
| ⚙️ 教官 · 後台 | `#/i/XXXX` | 完整編輯面板 | — | — |
| 📺 大螢幕 / 投影 | `#/b/XXXX` | 完整內容（含圖片/影片） | 永遠開 | ❌ 無視鎖 |
| 📱 學員手機 | `#/s/XXXX` | 完整內容 | 預設關 | ✅ 教官開才出聲 |

## 內建內容

- **非創傷（內科）初步評估**：10 步驟（現場安全 → 運送優先）
- **創傷初步評估**：11 步驟（含徒手頸椎固定、jaw thrust、致命出血控制）

每個步驟都可在「教官 · 後台管理」中修改 / 新增 / 刪除 / 重排。

## 已知問題

- **iOS Safari 第一次播放語音需點畫面一下**（瀏覽器音訊安全限制）
- **圖片/影片** 目前未上雲，需手動匯出/匯入跨裝置
- **Firebase Database 規則** 預設「test mode」30 天後到期，到期前要換成正式規則（之後再處理）

## 證據基礎

設計參考下列教育學原則：

- **認知負荷理論**（Sweller, 1988）：示範一次後直接操作會超載工作記憶；視覺輔助降低 extraneous load
- **多模態學習**（Mayer's CTML）：圖 + 文 + 語音的同步呈現比單一通道更易記
- **標準化視訊示範**：在 AHA/BLS 與 PHTLS 教師培訓中已成為標準教具
- 步驟流程依台灣 EMT-1 訓練綱要、PHTLS（10ed）、NAEMSP 共識
